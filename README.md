# リアライフ 不動産売却査定サイト

売却査定の反響獲得用LPです。静的サイト（HTML/CSS/JSのみ）なので、サーバー不要でGitHub Pagesで公開できます。

## 仕組み
1. お客様がフォームに入力します（物件種別、所在地、物件情報、お客様情報）。
2. 「LINEで査定を依頼する」を押すと、リアライフLINE公式アカウント（`@071luwzd`）のトーク画面が開きます。入力内容は本文に入った状態です。
3. お客様が送信すると、LINE公式アカウントのチャットに依頼が届きます。

サーバーやデータベースは使っていないため、個人情報がサイト側に保存されることはありません。

## ファイル
- `index.html`：ページ本体
- `style.css`：デザイン（realife-websiteと同じネイビーとゴールドを使用）
- `script.js`：ステップフォームとLINE本文の生成（`LINE_ID`でアカウントを指定）
- `assets/`：ロゴ、ファビコン、ヒーロー画像（realife-websiteからコピー）

## 公開手順（GitHub Pages）
1. GitHubで新しいリポジトリを作成します（例：`realife-satei`）。
2. このフォルダをpushします。
3. Settings → Pages → Branch: `main` / root を選び、保存します。
4. 独自ドメインを使う場合は、`CNAME`ファイルを追加し、DNSを設定します（例：`satei.realife-group.jp`）。
